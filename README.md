# 🌱 EcoTrack – Android Application

## 📌 About the Project
EcoTrack is an Android application developed to provide users with a simple and user-friendly mobile experience. The application is built using modern Android development technologies.

## 🚀 Technologies Used
- Kotlin
- Android Studio
- Jetpack Compose
- Material Design 3
- Gradle

## ✨ Key Features
- User-friendly interface
- Modern Android UI
- Easy navigation
- Multiple application screens
- Responsive design

## 📱 Application Details
- **Project Name:** EcoTrack
- **Platform:** Android
- **Language:** Kotlin
- **UI Framework:** Jetpack Compose
- **IDE:** Android Studio

## ⚙️ How to Run the Project

1. Download or clone this repository.
2. Open Android Studio.
3. Select Open Project.
4. Choose the EcoTrack project folder.
5. Wait for Gradle Sync to complete.
6. Connect an Android device or start an emulator.
7. Click the Run button.
